# astroagent brand

## The mark

**Stretch to light**: a stretch curve, the one that lifts faint linear data out of the dark, ends in a star, inside the frame of the image. It names what astroagent does (processing), not the hardware.

## Files

| File | Use |
|---|---|
| `astroagent-symbol.svg` | Symbol, night ink frame and curve, OIII star. Default from 48 px up |
| `astroagent-symbol-small.svg` | Small-size cut (thicker frame and curve, larger star) for 16-47 px |
| `astroagent-symbol-reversed.svg` | Symbol on dark backgrounds |
| `astroagent-symbol-black.svg`, `-white.svg` | One-colour versions (engraving, stamps, single-colour print) |
| `astroagent-app-icon.svg` | Night tile, light curve, OIII star: app icon, avatar, favicon |
| `astroagent-horizontal(-reversed/-black).svg` | Main lockup |
| `astroagent-stacked(-reversed).svg` | Square spaces (social avatar with name, stickers) |
| `astroagent-wordmark(-reversed).svg` | Name alone |
| `../kit/` | favicon.ico, favicon.svg, PNG icons, apple-touch-icon, webmanifest, head snippet |

## Colour

| Name | HEX | RGB | Role |
|---|---|---|---|
| Night | `#0E1A2B` | 14, 26, 43 | Frame, curve and name on light backgrounds; dark backgrounds |
| OIII | `#14A3A0` | 20, 163, 160 | The star. The only colour in the mark |
| H-alpha | `#E5484D` | 229, 72, 77 | Secondary accent for the site and documents. Never in the mark |
| Light | `#E9EEF4` | 233, 238, 244 | Frame, curve and name on dark backgrounds |
| Sky | `#0B1220` | 11, 18, 32 | Darkest background (site) |

The palette follows the HOO narrowband palette: OIII teal and H-alpha red on a night sky.

## Typography

- Name: **Sora SemiBold**, lowercase, converted to outlines in the masters (no font needed).
- Site and documents: **IBM Plex Sans** for text, **IBM Plex Mono** for commands and code.
- All three under the SIL Open Font License.

## Clear space and sizes

- Clear space around the mark: the width of the frame's border × 2 (about 1/6 of the symbol's height) on every side.
- Minimum size: symbol 16 px with the small-size cut, 48 px with the standard symbol; horizontal lockup 120 px wide.

## Do not

- Recolour the star in another hue, or add a gradient, glow or shadow.
- Separate the star from the curve, or rotate or mirror the symbol.
- Put the night version on a dark background or the light version on a light one.
- Retype the name in another font.
